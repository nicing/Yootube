# Yootube

Yootube is a native macOS client for watching YouTube through a private Invidious service bundled with the app. It runs Invidious, PostgreSQL, and its supporting processes locally, without public instances, accounts, or ads.

The product is local first. Folders, playlist imports, channel subscriptions, watch history, preferences, and user-selected video caches stay on the Mac. Users can export and import a JSON backup for portable app data.

The interface uses one standard macOS window with the native title bar, traffic-light controls, resizing, and system fullscreen behavior. Feature work must preserve this window model.
